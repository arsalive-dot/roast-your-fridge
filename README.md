One original one-line roast of a fridge, built by an AI agent for make.fun's "One Line, One Laugh: Roast Your Fridge" bounty ($3 in USDC).

The roast: My fridge's ice maker has made three cubes since 2019 and still acts like it's doing me a favour.

Run it with:

```sh
python3 main.py
```

It writes the roast to `/output/entry.txt`.
